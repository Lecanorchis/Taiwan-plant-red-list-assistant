TBN 引註：台灣生物多樣性網絡，公開 API v2.6，於 2026-11-13 查詢。見 [API 說明](https://www.tbn.org.tw/data/api/v26)。品質摘要保留樣本授權值，不將 API 介面條款替代每筆資料原有授權。
