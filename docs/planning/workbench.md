# 畫面與操作流程草案

本文件為 [第一版設計](README.md) 的操作規格。框線內的名稱、筆數、時間及狀態均為虛構示意；沒有建立可執行網頁。

## 1. 導覽與共同操作

入口提供「建立清單」與「匯入備份」。已有本機資料時，直接顯示專案總覽，允許切換或另建專案。每個專案固定名錄、評估範圍及準則版本；更新參考資料時先顯示差異，使用者選擇是否採用。

全站固定提供專案名稱、儲存狀態、資料包入口與說明。儲存狀態只在瀏覽器資料交易成功後顯示「已儲存於此瀏覽器」。失敗時保留尚未寫入的內容並提供重試，不顯示成功提示。

「上次產生備份」與「已儲存於此瀏覽器」分開顯示。產生下載檔不代表已確認使用者將檔案保存到磁碟。更換瀏覽器、裝置或網站網址時，透過備份移轉資料。

## 2. 專案總覽與清單

```text
┌───────────────────────────────────────────────────────────────┐
│ 示例專案 ▾          已儲存於此瀏覽器          [資料包] [說明]   │
├───────────────────────────────────────────────────────────────┤
│ 評估範圍：新版範圍    名錄：所選 TaiCOL 快照    資料截止日：… │
│ [加入分類群] [匯入名單]             搜尋名稱…   階段／問題 ▾ │
│                                                               │
│ 分類群       分類      分布      準則      區域調整    待辦   │
│ 示例甲       已確認    進行中    未開始    未開始       3      │
│ 示例乙       待確認    未開始    未開始    未開始       1      │
│ 示例丙       已確認    已查核    已確認    已確認       0      │
│                                                               │
│ 已完成個人查核 1／3                 [繼續上次工作]            │
└───────────────────────────────────────────────────────────────┘
```

- 搜尋與篩選不改動資料；排序順序可保存。
- 進度以各階段狀態與具體待辦呈現，不把已填欄位比例當成科學評估完成度。
- 可暫停某分類群並換到下一筆，無須將它改成 DD 或 NA 才能繼續。
- 不適用、尚未評估、資料不足與個人查核完成分別顯示。
- 刪除優先採封存並可恢復；確實清除本機資料另列明確操作。

### 加入分類群

使用者可選擇名稱逐筆／多行輸入、依屬／科展開，或匯入含名稱的 CSV。匯入先預覽欄位、編碼、匹配結果與問題列，再選擇要加入的項目。

```text
輸入：示例屬                         名錄：專案指定快照
[搜尋／展開]

候選清單（示意）
[✓] 示例甲      種        接受名       尚未加入
[✓] 示例乙甲    亞種      接受名       尚未加入
[ ] 示例乙      種        整理父層     已有下位單位
[ ] 示例舊名    異名      指向示例甲   不另建評估
[?] 未解名稱    待確認    需選擇匹配或保留未解項

[返回修改] [加入所選項目]
```

依真正的分類階層展開，不依字串前綴猜測。保留原始輸入；精確接受名匹配、異名對應、近似候選及無匹配分開顯示。近似名稱不自動採用。已有種下評估單位時，種層級可作整理父層，不重複計入評估總數。使用者尚未確認的種下歸屬不由程式推定。

有下位單位時另提示是否完整涵蓋母種；涵蓋未解的母種保留整理頁與未歸屬資料，不自動丟棄或創造原名變種。來源的台灣旗標與新版所有島嶼的適用性分開，未納入候選的項目仍可回查。[靜態視覺草圖與實際樣本](pilot-scenarios.md)

## 3. 單一分類群工作區與分類查核

```text
┌──────────────┬───────────────────────────────────┬─────────────┐
│ 清單         │ 示例甲 · 種                       │ 證據／說明  │
│ 搜尋…        │ 分類 > 分布 > 準則 > 區域 > 檢查  │             │
│ > 示例甲     ├───────────────────────────────────┤ 名錄版本    │
│   示例乙     │ 原始輸入名：…                     │ 原始來源    │
│   示例丙     │ 接受名與命名者：…                 │ 引用與頁碼  │
│              │ 分類階層／識別碼／異名：…         │             │
│              │ 採用分類處理：名錄預設／人工處理   │ [新增證據]  │
│              │ 區域適用性：待確認                │ [請 AI 協助]│
│              │ 原生與野生狀態、理由與證據：…     │             │
│              │ [確認此步驟]      [下一分類群]     │             │
└──────────────┴───────────────────────────────────┴─────────────┘
```

分類畫面提供接受名、命名者、種下階層、上位分類、異名、TaiCOL 與其他來源識別碼、2017 名稱對應及分類概念註記。更改接受名時顯示受影響的紀錄、計算與判斷，不直接將舊紀錄視為符合新分類概念。

人工分類處理保留名錄原值、新值、理由、證據及確認者。爭議未解仍可儲存及蒐集資料，但分類步驟保留待確認。原生性、野生狀態及適用性分開記錄，區域適用性由使用者確認。

## 4. 分布資料匯入與查核

匯入來源包括 TBN、使用者 CSV／GeoJSON 與手動紀錄。其他 API 由後續介接增加。先確認分類群來源識別碼、查詢範圍與可用過濾條件，再執行匯入。

下載顯示已取得筆數、頁數與是否完成。中斷、取消或達到上限時保留已取得內容及續查資訊，標示「部分資料」；零筆完整結果與查詢失敗分開處理。

本輪瀏覽器查核顯示直接讀取 TBN 受 CORS 限制，因此即時匯入建議經公開查詢轉接；未提供轉接時，介面明確引導檔案匯入。另建議支援 TBN 原始 JSON／快照匯入作替代路徑。[查核與建議](feasibility.md)

```text
┌────────────────────────────────┬──────────────────────────────┐
│ 地圖                           │ 紀錄表                       │
│ [本島] [金門] [馬祖] [其他島嶼] │ 搜尋…   年代／問題／用途 ▾   │
│ 圖層：                         │ ID    日期    分類  空間用途  │
│ ☑ 原始點   ☑ 已採用點          │ r1    …       已核  採用      │
│ ☑ 不確定範圍  ☐ AOO  ☐ EOO    │ r2    …       待核  待確認    │
│                                │ r3    …       已核  不採用    │
├────────────────────────────────┴──────────────────────────────┤
│ 已選 r2  原始值／修正值／來源／關聯標本／查核歷程            │
│ 分類可信度：…    證據用途：…    空間用途：…    理由：…      │
│ [保存查核] [下一筆待查]          [計算 AOO／EOO]               │
└───────────────────────────────────────────────────────────────┘
```

紀錄可支持多種證據用途，例如歷史分布與分類查核，但未必適合空間計算。座標不精確的紀錄仍可保留其文獻價值。批次決策先顯示受影響紀錄，填共同理由後確認；個別例外可另行調整。

疑似重複依來源識別碼、標本號、日期、採集資訊與座標等提出候選，不只看座標相同。紀錄更正保留原值、方法及不確定性。無法判斷現存／歷史、區內／區外或野生／栽培時保留未知。

### 空間計算結果

每次計算呈現輸入數量、待查數量、下載完整性、採用年代、方法、AOO、EOO、網格與不確定性說明。計算結果分成工具產生值與使用者採用值；人工採用不同數值時保留理由與證據。

重新選點後，舊結果仍可回查但標示過期。使用者可重新計算，再確認受影響的準則。威脅定義地點數另有表單與判斷依據，不由網格或點數直接填入。底圖與搜尋框不自動裁切 EOO。

## 5. 準則與區域調整

```text
區內初評                                      [準則說明]
候選等級：尚未形成      使用者採用：尚未確認

準則   狀態       證據與缺漏                          [展開]
A      未評估     待提供下降證據與適用時間窗
B      資料不足   已有空間結果；其他必要條件待查
C      未評估     成熟個體數與下降資訊待查
D      未評估     小族群或受限分布條件待查
E      未評估     尚無定量分析結果

展開 B
EOO／AOO：來源計算批次…      [檢視輸入]
破碎化／威脅定義地點／持續下降／極端波動：…
判斷理由：…      證據：…      不確定性：…
[保存] [請 AI 協助此準則]
```

輸入提供數值、估計範圍、單位、時間窗、方法與證據。未知與零不同；沒有資料不預設為「否」。系統提示規則條件與資料缺漏，使用者確認採用的判斷。完整的欄位分組見 [資料與交換規格](data-contract.md)。

區域調整顯示區內初評，再填區外族群、有效移入、未來變化、移入依賴及證據，最後記錄維持／調升／調降／不適用的理由及採用類別。依指引處理未知狀況並記錄限制，不要求每個問題都必須有確定答案才能保存已說明的判斷。

「完成個人查核」表示使用者檢查目前資料、記錄必要的不確定性並確認結果，不表示官方審定。DD 等科學類別與查核完成狀態互不替代；未開始的評估也不以填入 NE 來假裝完成工作。

## 6. AI 任務與建議審閱

在總覽或單一分類群中選「請 AI 協助」，選擇彙整、分類、分布或評估任務。預設只選目前任務需要的內容，並顯示是否含座標、附件或私人註記。使用者確認內容後下載任務包，自行交給可讀取該資料的 AI 環境。

彙整任務可涵蓋清單進度；分類、分布與評估任務預設一次一個分類群。任務包包含純文字任務說明與所需技能入口；若外部環境不支援讀 ZIP，可自行解壓後提供其中檔案。

```text
AI 建議審閱                         示例甲 · 原評估版本 4
任務：查核準則 B                    [查看原任務與交換內容]

建議 1／3                            狀態：可審閱
欄位：準則 B 判斷理由
目前值：尚未填寫
建議值：現有資料僅支持空間分析，仍需查核其他必要條件。
理由：…                              來源：證據 e1

[接受此建議] [編輯後採用] [略過]     [下一項]
```

匯入建議只建立待審紀錄。格式錯誤、引用不存在、原評估已變更或計算版本不同時，顯示具體問題並停止該項採用；仍可閱讀建議內容。跨欄位相依的建議以一組審閱，避免只採用了文字卻遺漏引用的證據。

AI 可以建議候選等級與理由，不能透過匯入檔自行標示人工查核完成。分類拆併、刪除資料或換評估範圍等較大變更，以待辦建議呈現，回到對應畫面由使用者操作。

## 7. 完整性檢查、資料包與還原

```text
資料包
○ 完整備份     清單、評估、紀錄、證據、歷程與附件
○ AI 任務包    僅包含所選任務需要的內容

本次內容：…    大小預估：…    外部連結但未附檔：…
狀態：2 個分類群尚未完成；仍可匯出
[檢視內容清單] [產生資料包]

匯入
[選擇完整備份或 AI 建議檔]
檔案驗證 → 顯示內容與相容性 → 還原新副本／進入建議審閱
```

完整性檢查區分資料結構問題、科學待辦與更新提醒。資料不足、未評估與待查均允許備份；損壞的內容不得冒充成功匯出。只有連結、沒有本機副本的附件要明確列出。

還原時先驗證，再預覽專案名稱、範圍、版本、筆數及附件。第一版建議還原成獨立本機副本，避免覆蓋既有工作。不同副本不自動合併；若格式較舊，以新副本完成遷移並保留原檔。未知的較新格式給出相容性說明，不靜默丟棄欄位。

## 8. 狀態、相依與可用性

工作階段使用 `not_started`、`in_progress`、`awaiting_review`、`completed`；`needs_review` 作為額外旗標，保留原先完成的歷程。評估內容另有資料不足、未知與科學類別。

| 改變 | 需要重新確認的內容 |
| --- | --- |
| 分類概念或評估範圍 | 紀錄歸屬、適用性、空間計算、準則與區域調整。 |
| 紀錄採用、座標或年代條件 | 使用這些輸入的空間計算與引用它的判斷。 |
| 成熟個體數、世代長度、威脅等證據 | 引用該資料的準則與候選等級。 |
| 區內初評或區外證據 | 區域調整。 |
| 名錄／規則可用新版本 | 提醒有更新；使用者採用後才使相依內容需查核。 |

所有狀態除顏色外都有文字。表單提供標籤、鍵盤操作與保留未完成輸入；地圖之外可使用紀錄表完成查核。窄畫面將側欄改為抽屜或頁籤，不要求同時顯示三欄。

離線時可操作已載入並保存的資料；外部查詢、未快取文獻與線上底圖明確顯示需要連線。完整離線載入與各瀏覽器支援程度，在實作驗證後才宣告。
