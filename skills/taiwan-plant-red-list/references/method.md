# 評估方法

每次固定區域、分類概念、評估日期及參考準則版本。可用 `sources iucn` 查官方文件。判讀依類別與準則 3.1、使用指引 16、區域指引 4.0。以下作為找證據與逐項核對的順序。

新版紅皮書使用 [region.json 的陸域範圍](region.json)。比較歷史評估時，另查當年的區域與分類概念。觀測資料的國別、行政區標籤及搜尋框只能協助篩選，近岸及離島紀錄需核對實際落點與原始採集地。對觀測涵蓋較少的島嶼，記錄補查的文獻或標本資料，以及仍存在的缺口。

## 適用性

記錄接受學名、種下階層、異名、可能混用的概念和採用來源。歷史名稱與現行分類對不上時，保留原名並說明是否可歸入本次分類概念。對拆分後的分類群逐一核對紀錄。變種納入本專案的個人評估範圍，並記錄其分類依據與區域適用政策。

依區域指引第 IV 章及附錄 3 檢查原生範圍、區內野生族群及繁殖。只有栽培或普通外來引入的分類群通常不適用。若涉及有利於保育的引入、邊緣族群或偶發出現，逐案對照區域指引並記錄判據。需要評估 RE 時，檢查搜尋強度、適當時段及最後可繁殖野生個體是否消失的證據。查不到觀測時保留不確定性。

## 區內初評

逐項保存 A–E 的證據及判斷。初評採有充分支持的最高風險類別，記下該類別符合的全部準則代碼。每項判斷記錄所用時間窗、單位、資料限制與合理範圍，並以官方準則核對代碼和不等式。

| 準則 | 需要查核 |
| --- | --- |
| A | 世代長度、對應時間窗及族群下降率。依 A1–A4 分開核對過去、未來、跨過去及未來，以及下降原因是否已停止、可逆、已知。 |
| B | B1 分布範圍 EOO、B2 占有面積 AOO，另需至少兩項條件 a–c 成立。a 檢查嚴重破碎化或依最嚴重合理威脅定義的地點數，b 檢查持續下降，c 檢查極端波動。 |
| C | 區內成熟個體數與持續下降，按 C1 的下降幅度／時間窗或 C2 的亞族群結構／極端波動核對。 |
| D | 成熟個體數極少。VU D2 另查範圍或地點受限，以及可在短時間內使風險升至 CR 或 EX 的合理威脅。 |
| E | 有定量滅絕風險分析時才核對模型、輸入、不確定性、風險機率及時間窗。 |

EOO 或 AOO 閾值命中時，只能得到 B1 或 B2 的空間門檻證據。點位、網格、行政區或調查站的數量無法直接作為威脅定義地點數。觀測筆數及其年度變化也不能直接估算成熟個體數或下降率。若資料不足以可靠評估風險，對照 DD 定義並說明限制及應優先收集的資料。若建議 LC 或 NT，說明資料如何排除受脅，並交代與門檻的距離。資料缺口與確認未達門檻使用不同欄位狀態。

## 區域調整

區外紀錄只供判讀區域調整。對照區域指引圖 3 及表 1，查區外同分類群的繁殖體能否抵達並成功繁殖、移入是否顯著、是否可能減少，以及區內族群是否仰賴移入維持。若為區域特有，記錄支持特有性的來源並說明維持初評的理由。區外有分布本身不足以支持降級。保留初評及代碼，另記區域類別、方向、幅度、依據及不確定性。證據仍在查核時保留 `pending`。

## 空間工具的解讀

`range` 只計算經人工選入的現存點位，底圖供定位。AOO 採 EPSG:6933 等面積投影的 2 × 2 公里網格，東西與南北各測試 0、500、1000、1500 公尺原點位移，回傳 16 種對齊中最小值、最大值及採用的原點。這是固定間距的敏感度取樣。EOO 採最小凸包，至少三個不共線的點才能估算。工具分開記錄凸包面積與用於初步比較的 EOO；後者若小於 AOO，按使用指引調整到 AOO。資料為零或凸包無法估算時以 `null` 表示相應缺值。保留截斷與未審閱筆數，並討論採樣遺漏、區域邊界、年代及空間不確定性。若有經審查的分布推估或補充資料，報告應記錄採用數值、方法與理由。
